# 📇 Agenda de Contactos en Python

Aplicación interactiva de consola desarrollada en Python que funciona como un sistema de gestión de contactos (CRUD), permitiendo administrar registros mediante estructuras de datos eficientes.

## 🚀 Funcionalidades
- **Añadir contacto:** Registro de nuevos contactos (Nombre y Teléfono).
- **Buscar contacto:** Búsqueda por nombre con manejo de errores si no existe.
- **Editar contacto:** Actualización de números telefónicos de registros existentes.
- **Eliminar contacto:** Remoción de contactos del sistema.
- **Mostrar todos:** Visualización completa de la lista de contactos guardados.

## 🛠️ Conceptos y Tecnologías Aplicadas
- **Estructuras de Datos:** Manejo de Diccionarios para pares clave-valor (nombre: teléfono), Listas y Tuplas.
- **Control de Flujo:** Bucles interactivos (`while`), condicionales (`if/elif/else`) y operadores booleanos.
- **Lenguaje/Entorno:** Python 3 | Visual Studio Code
